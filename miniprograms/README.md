# 小唯种植体管理系统 - 微信小程序

## 项目概述

基于小唯种植体管理系统网站开发的两个微信小程序：

1. **客户端小程序** (`miniprograms/client/`) - 患者用户专用
2. **管理端小程序** (`miniprograms/admin/`) - 平台、诊所、经销商、药店、工厂端口共用

## 导入微信开发者工具

### 1. 下载微信开发者工具
- 官网：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 选择稳定版 Stable Build

### 2. 导入客户端小程序
1. 打开微信开发者工具
2. 点击"导入项目"
3. 目录选择：`小唯管理系统/miniprograms/client/`
4. AppID 填写你的小程序AppID（或选择"测试号"）
5. 点击"导入"

### 3. 导入管理端小程序
1. 同样点击"导入项目"
2. 目录选择：`小唯管理系统/miniprograms/admin/`
3. AppID 填写另一个小程序AppID（或选择"测试号"）
4. 点击"导入"

## API 配置

两个小程序的 API 地址已在 `app.js` 中配置：

```javascript
globalData: {
  apiBase: 'https://xiaowei-backend.loca.lt/api'  // 后端API地址
}
```

如需修改，编辑各自 `app.js` 中的 `apiBase` 字段。

> **注意**：微信小程序要求 HTTPS 域名。在开发者工具中，点击右上角"详情" → "本地设置" → 勾选"不校验合法域名"即可在开发阶段使用任意域名。

## 管理端小程序功能

### 端口切换
管理端支持 5 个端口，登录后选择端口进入对应管理界面：

| 端口 | 图标 | 核心功能 |
|------|------|---------|
| 平台端 | 🏠 | 诊所/药店/经销商管理、种植体卡管理、商场管理、病历中心、结算中心、权限配置、注册审核 |
| 诊所端 | 🏥 | 核销登记、患者建档、病人信息查询、加工单管理、植体管理、收支明细、提现申请 |
| 经销商端 | 👤 | 诊所管理、药房管理、佣金明细、提现申请 |
| 药店端 | 💊 | 种植卡管理、库存查看、采购管理、财务收支、客户管理 |
| 工厂端 | 🏭 | 订单管理、收发货管理、质检记录、异常反馈、病历查询、财务收支 |

### 管理列表页
- 左侧菜单栏按端口显示对应功能模块
- 右侧数据列表支持搜索、状态筛选
- 点击"新增"弹出底部表单进行创建
- 点击"编辑"可修改记录
- 点击"删除"确认后删除记录
- API 不可用时自动回退到本地 Mock 数据

### 病人病历查询
- 统计卡片：总患者数、种植患者数、种植体数、已完成手术数
- 支持按姓名、诊断、医生、种植体型号搜索
- 支持按类型筛选：种植、修复、正畸
- 患者详情弹窗显示基本信息和病历信息
- 诊所端和平台端可查看联系电话（可拨号），其他端口隐藏

### 注册审核
- 三个标签页：待审核、已通过、已驳回
- 支持通过/驳回操作
- 驳回时需填写驳回原因
- 实时更新各状态数量

## 技术要点

### API 请求封装
两个小程序共用相同的请求模式：
- 统一封装 `request()` 方法，自动携带 token
- 401 状态自动跳转登录页
- 支持 GET/POST/PUT/DELETE
- Promise 风格调用

### 本地存储
- token 存储在 `wx.getStorageSync('token')`
- 用户信息存储在 `wx.getStorageSync('userInfo')`
- 管理端端口选择存储在 `wx.getStorageSync('port')`

### 权限控制
- 管理端根据用户 `ports` 字段显示可用端口
- 病人病历查询根据端口控制电话可见性
- 各端口菜单通过 `menu.js` 统一配置

### UI 设计
- 主色调：`#1abc9c`（青绿色）
- 卡片式布局，圆角 16rpx
- 渐变头部设计
- 底部弹窗表单交互
- 响应式适配各机型

## 发布前注意事项

1. **AppID**：替换 `project.config.json` 中的 `wxYOUR_CLIENT_APPID` 和 `wxYOUR_ADMIN_APPID`
2. **域名配置**：在微信公众平台 → 开发管理 → 开发设置 → 服务器域名，添加 API 域名
3. **HTTPS**：确保后端 API 使用 HTTPS
4. **TabBar 图标**：当前使用纯文字 tabBar，如需图标请准备 81x81px PNG 图片放入 `images/` 目录，并在 `app.json` 中配置 `iconPath`
5. **权限配置**：确保后端 API 支持小程序的请求来源

## 常见问题

**Q: 导入后报错"找不到 sitemap.json"？**
A: 确保 `sitemap.json` 文件在项目根目录。

**Q: API 请求失败？**
A: 在开发者工具中勾选"不校验合法域名"，或配置正确的 HTTPS 域名。

**Q: 管理端看不到某些端口？**
A: 端口可见性取决于登录账号的 `ports` 权限。admin 账号拥有所有端口权限。

**Q: 数据显示的是 Mock 数据？**
A: 当后端 API 不可用时，小程序会自动回退到内置 Mock 数据，方便预览界面效果。
