1 购买腾讯云服务器

1.1 购买入口

  1. 访问腾讯云官网：https://cloud.tencent.com
  2. 注册/登录账号，完成实名认证
  3. 进入「轻量应用服务器」产品页
  4. 选择新用户特惠套餐

1.2 推荐配置

配置项推荐值
规格4核8G 10M带宽
系统盘200GB SSD
月流量2000GB/月
操作系统Ubuntu 22.04 LTS
地域国内（北京/上海/广州，离用户近的）
价格约368-450元/年（新用户）

1.3 购买后操作

  1. 进入控制台 → 轻量应用服务器
  2. 找到服务器实例，记录公网IP地址
  3. 点击「更多」→「管理」→ 重置密码，设置root密码
  4. 确认安全组已开放端口：22(SSH)、80(HTTP)、443(HTTPS)
重要：请妥善保存服务器公网IP和root密码，后续步骤需要使用。

2 连接服务器

2.1 Windows 系统使用 SSH 连接

Windows 10/11 自带 SSH 客户端，打开 PowerShell 或终端：

# 替换 YOUR_IP 为服务器公网IP ssh root@YOUR_IP # 输入密码时不会显示字符，直接输入回车即可

2.2 使用腾讯云 WebShell（备选）

  1. 登录腾讯云控制台
  2. 轻量应用服务器 → 找到实例 → 点击「登录」
  3. 选择「使用标准登录」→ 输入 root 和密码
  4. 直接在浏览器中操作终端

2.3 首次登录后更新系统

apt update && apt upgrade -y

3 安装服务器环境 一键脚本

此步骤安装 MySQL 8.0 + Node.js 20 + Nginx + PM2 + Certbot，约需5-10分钟。

3.1 上传并运行安装脚本

在本地电脑打开 PowerShell，上传 setup.sh 到服务器：

# 在本地 PowerShell 中执行 scp -r "项目路径\小唯管理系统\deploy\setup.sh" root@YOUR_IP:/root/

然后 SSH 连接到服务器运行：

# SSH连接服务器后执行 cd /root chmod +x setup.sh sudo bash setup.sh

3.2 脚本交互输入

脚本会提示输入：

提示输入内容说明
MySQL root密码Xiaowei@2025!自定义密码，请记住
网站域名xiaowei.com你的实际域名

3.3 安装完成标志

看到以下输出表示安装成功：

======================================== 环境安装完成！ ======================================== 已安装组件: MySQL 8.0 - 数据库服务 Node.js v20.x.x - 后端运行环境 PM2 x.x.x - 进程管理器 Nginx x.x - Web服务器/反向代理 Certbot - SSL证书工具 UFW - 防火墙

4 上传项目代码

4.1 打包项目代码

在本地电脑将项目代码打包（不含 node_modules）：

# 在本地 PowerShell 中，进入项目根目录 cd "项目路径\小唯管理系统" # 创建压缩包（排除 node_modules 和 .git） Compress-Archive -Path index.html,css,js,backend,deploy -DestinationPath xiaowei.zip -Force

4.2 上传到服务器

# 上传压缩包到服务器 scp xiaowei.zip root@YOUR_IP:/root/ # SSH连接服务器后解压 ssh root@YOUR_IP cd /root unzip xiaowei.zip -d 小唯管理系统
提示：也可以使用 Git 方式上传，先在 GitHub 创建私有仓库，然后在服务器上 git clone。

# 登录MySQL mysql -u root -p # 备份数据库 mysqldump -u root -p xiaowei_system > backup.sql # 恢复数据库 mysql -u root -p xiaowei_system < backup.sql

# 1. 上传新代码到服务器 scp -r 新代码/* root@YOUR_IP:/root/小唯管理系统/ # 2. SSH连接服务器，重新部署 ssh root@YOUR_IP cd /root/小唯管理系统/deploy sudo bash deploy.sh # 3. 重启服务 pm2 restart xiaowei-backend nginx -s reload

# 创建备份脚本 mkdir -p /root/backup cat > /root/backup/backup.sh << 'EOF' #!/bin/bash DATE=$(date +%Y%m%d) mysqldump -u root -p"Xiaowei@2025!" xiaowei_system > /root/backup/xiaowei_${DATE}.sql # 保留最近7天的备份 find /root/backup -name "*.sql" -mtime +7 -delete EOF chmod +x /root/backup/backup.sh # 设置每天凌晨3点自动备份 crontab -e # 添加以下行： 0 3 * * * /root/backup/backup.sh

常见问题

Q1: 访问网站显示502 Bad Gateway

后端服务可能未启动，执行：

pm2 status # 检查后端状态 pm2 restart xiaowei-backend # 重启后端 pm2 logs xiaowei-backend # 查看错误日志

Q2: 登录提示"服务器内部错误"

检查数据库连接是否正常：

mysql -u root -p # 确认密码正确 USE xiaowei_system; SHOW TABLES; # 确认表已创建 SELECT * FROM users; # 确认有数据

Q3: 图片上传失败

检查上传目录权限：

ls -la /var/www/xiaowei/backend/uploads/ chown -R www-data:www-data /var/www/xiaowei/backend/uploads/ chmod -R 775 /var/www/xiaowei/backend/uploads/

Q4: SSL证书过期

证书有效期90天，已配置自动续期。手动续期：

certbot renew systemctl reload nginx

Q5: 网站访问慢

可能原因和解决方案：

  • 带宽不够：升级服务器带宽
  • 数据库慢查询：检查MySQL慢查询日志
  • Nginx未开启Gzip：检查nginx.conf中gzip配置
  • 静态资源未缓存：检查浏览器缓存

Q6: 如何迁移到新服务器

  1. 在新服务器运行 setup.sh
  2. 备份旧服务器数据库：mysqldump -u root -p xiaowei_system > backup.sql
  3. 上传 backup.sql 到新服务器，导入：mysql -u root -p xiaowei_system < backup.sql
  4. 上传项目代码到新服务器
  5. 运行 deploy.sh 完成部署
  6. 修改域名DNS解析到新服务器IP
  7. 运行 ssl.sh 申请SSL证书
